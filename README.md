##Project Overview & Objective
The primary objective of this task was to design and build a responsive, interactive frontend portal. Rather than building a standard static page, this website behaves like a Single Page Application (SPA). It seamlessly balances two distinct UI layouts within a single workspace:

1.The Primary Workspace Layer: A modern corporate homepage featuring a clean grid layout, user informational metrics, and actionable featured cards.

2.The Dynamic Content View Layer: An elegant, isolated "separate page" presentation that activates instantly when an interaction occurs.

##How the Application Works
When a user launches the website, the application initializes the primary home screen, rendering a prominent, colored hero banner alongside interactive grid content cards.

The core interactivity lies in the transition between the home view and the deep-dive view. Instead of forcing the web browser to request a completely separate .html file from a server—which causes an abrupt, slow screen flash—the transition is controlled directly on the client side using the Document Object Model (DOM).

##Technical Tools & Stack Used
This project was built entirely using standard native web technologies, eliminating the need for heavy external frameworks:

HTML5 (HyperText Markup Language): Used to construct the core skeleton of the application. It establishes semantic structures like <header>, <section>, and <div> containers. Crucially, it utilizes customized data-* attributes to store dynamic text directly within the components.

CSS3 (Cascading Style Sheets): Responsible for the visual presentation and styling. It utilizes CSS Flexbox and CSS Grid to ensure elements scale naturally across desktop and mobile screens. Advanced design features like backdrop-filter: blur() create the frosted-glass effect, while absolute fixed positioning locks the full-screen background view into place.

Vanilla JavaScript (ES6+): Provides the logical architecture. It manages event listeners to catch user interactions, manipulates classes in real-time to change section visibility, and modifies inner element text dynamically based on what the user selects.

VS Code (Visual Studio Code): The primary integrated development environment (IDE) used to write, format, and organize the source code.

Live Server Extension: A development tool inside VS Code used to spin up a local development server, allowing real-time browser preview updates instantly upon saving our code changes.
